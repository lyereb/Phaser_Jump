# 主菜单设置弹窗

## 使用

点击主菜单原有设置按钮，打开设置弹窗。弹窗沿用现有返回确认与结算UI的奶油色圆角卡片、粉色描边、半透明深色遮罩、黄色完成按钮及按压回弹反馈；保留主菜单作为底图，打开时暂停主菜单。

目前只有一个“音量”开关，没有滑块或额外设置。绿色“开”表示开启背景音乐和全部音效，灰粉色“关”表示全局静音。关闭立即对正在播放的声音生效，并抑制后续音效；重新开启恢复原有各音轨的混音音量，不把音乐和音效全部改成同一个音量。

点击“完成”、右上关闭按钮或按 Escape 返回原菜单。点击遮罩空白不会关闭，也不会穿透为角色起跳或开始游戏。关闭时取消尚未执行的按钮操作，因此在开关回弹期间关闭弹窗不会意外在返回后改变设置。

## 保存与音频行为

声音默认开启。本地保存键为 `phaser-jump-sound-enabled`，值 `1` 代表开启，`0` 代表关闭。状态跨弹窗关闭/重新打开、主菜单和游戏新局保持，刷新页面后也会读取保存值。读取失败或无有效设置时默认开启；写入被阻止时，本会话仍可以切换，但无法保证刷新后保留。

开关使用 Phaser 共享 SoundManager 的全局 `mute`，控制背景音乐、跳跃、叠放、金币、道具、庆祝及UI提示音，不修改各声音原有音量配置。关闭时音乐可以保持静默播放，既不新建多余轨道，也不把开关当成暂停/重开音乐。返回确认对BGM的暂停/恢复行为仍然保留，恢复时也会应用当前声音偏好。

等待Web Audio解锁的音效会再次检查开关，因此等待期间关闭声音后，解锁不会漏播该音效。关闭开关本身不播放提示音；开启时会使用原UI提示音确认。浏览器自动播放权限和设备系统音量仍由浏览器/操作系统控制，本开关不会修改系统音量。

## 修改文件

| 文件 | 作用 |
| --- | --- |
| `src/game/audioPreferences.ts` | 默认开启、本地保存、全场景共享声音偏好 |
| `src/game/audio.ts` | 应用全局静音、抑制关闭时音效、保持音乐混音和暂停恢复 |
| `src/game/scenes/Settings.ts` | 单一音量开关、完成/关闭/Escape、弹窗布局与输入清理 |
| `src/game/scenes/MainMenu.ts` | 原设置入口、暂停/恢复门禁、启动读取声音偏好 |
| `src/game/main.ts` | 注册设置场景 |

没有增加图片、音频素材或依赖，不修改金币、皮肤、道具概率和跳跃物理，也没有重新初始化项目。
