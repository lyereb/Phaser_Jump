# 实体触碰 checkpoint（50标签递增）

已在现有 Phaser 4.2.1 项目中接入，保留当前引擎、背景与AI福袋。checkpoint只负责视觉目标与爆袋提示，不增加分数，也不提供复活或存档。

## 当前游戏行为

福袋标签依次为50、100、150等，但领取不再要求分数达到标签数值。开局已创建并放置首个50目标，初始在屏幕上方；角色越向上跳，目标逐渐进入视野。碰到后立即预置下一个目标，袋子上的数字由代码动态绘制。

**游戏进行中，角色身体实际碰到福袋或红绳就立即触发爆袋。** 上升和下降都可以触发，不必等头部越过红绳，也不必等成功落到新盒子。碰到后再落回旧盒或随后失败，不撤销已触发的目标；同一标签最多一次。

角色虽然在目标上方但身体未接触、横向没有碰到福袋且身体也没有碰到红绳、隐藏的目标，以及仅得分超过标签，都不触发。福袋检测使用当前变换后的图像包围框，红绳检测匹配弧线与角色身体的实际交叠。

横绳随屏幕宽度和镜头水平位置更新，原有连续接近投影与260毫秒平滑移动保留；米数只影响目标接近的呈现，不参与领取条件。下一目标提前放在上方，不会在同一福袋上重复领取。

爆袋动画保留短暂膨胀、左右两半旋转飞出、红黄纸屑和闪光扩散；音效复用 `public/assets/Audio/jackpot.mp3`。返回确认窗口暂停期间，物理触碰检测与动画都冻结，选择继续后恢复；重新开始重置到50标签，清理上一局全部特效。

弹簧动作也使用实际触碰规则，空中碰到就爆袋，不等加分或落地。**整次弹簧动作固定加10米**，含踩中弹簧箱的启动落地，不另加1～5米连击奖励；此规则详见 `special-boxes.md`。
