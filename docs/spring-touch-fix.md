# 弹簧10米与checkpoint触碰修复

## 弹簧计分

整次弹簧动作成功落到最高平台后，**固定增加10米**。踩中弹簧箱的启动落地也包含在这10米中，不再额外累加普通／完美分数，因此不会变成12、15、49、50或55米。普通和完美踩中、低或高连击时都一样。

例如从37米开始，动作结束显示47米；从49米开始，结束显示59米，不再升到104米。

角色仍弹起约十个视觉盒高，两侧十个普通盒依次飞入、完全居中叠好，并自动落到第十盒。自动十盒会计入完美叠放统计，但不使用每盒2～5米的连击计分，也不延长人物连击。启动盒的真实完美判定仍保留；普通跳跃原有1～5米计分、金币奖励、护盾和10%特殊概率没有改动。

结算页面因此会显示正确的10米增量，同时保留真实盒数：弹簧启动盒1个，加自动叠放10个，共11个盒子；完美启动时完美叠放数为11，非完美启动时为10。

## checkpoint触发

**角色身体实际碰到福袋或红绳立即爆袋**，不要求米数达到50、100等标签，也不用等成功落地。上升和下降都能触发。袋子上的50、100、150等数字继续保留，作为按50递增的目标标签，不是领取门槛。

同一个目标只触发一次，通过后即提前摆放下一目标。没有实际接触时不会仅凭分数触发；身体完全在绳上方但没有碰到、横向远离福袋且没碰红绳、隐藏目标都不误触发。已经触碰后再落回旧盒或随后失败，不撤销爆袋结果，checkpoint也不额外加分。

开局目标预置在屏幕上方、平滑接近、AI福袋与数字、左右碎片和纸屑动画都保留。暂停确认窗口会冻结触碰检测和爆袋动画，继续游戏原位置恢复；重开从50标签开始并清理上一局特效。

## 原因与修改

原弹簧自动十盒逐个调用完美落地计分，导致每盒最多加5米。现在只在整次弹簧完成时统一加10米，并将自动盒的完美叠放统计与人物连击计分分离。

原checkpoint先记录上升越线，再要求新盒成功落地且米数达标。现在每个物理固定步检查身体与福袋当前包围框、红绳实际弧线的接触，命中立即领取与爆袋，通过目标标签去重。

修改位于 `src/game/scenes/Game.ts`、`src/game/checkpoints.ts` 和 `src/game/checkpointProgress.ts`。没有更换引擎、没有重新生成或替换素材，也没有发布网站。

## 验证与试玩

类型检查和生产构建通过。11项新规则场景测试、11项结算回归、11项返回确认回归、10项道具场景回归，以及14项checkpoint、12项道具规则、6项弹簧弹道纯逻辑测试全部通过，共75项检查。

包含六种普通／完美与低高连击的弹簧组合、0米空中碰到50标签即时爆袋、下降与身体碰红绳、未触碰不领取、重复触碰去重、碰到后失败、暂停续接、结算10米与重试清零、金币端点和一次性护盾。所有验证使用独立QA金币键，不修改正常游戏金币。

刷新 `http://127.0.0.1:8080/` 即可体验。开发环境可打开右上角返回按钮下方的“调试”，选择生成弹簧盒，真实跳跃踩住后即可验证固定10米。源码、旧规则与测试备份保留在 `.work/spring-touch-fix/`，不进入生产构建。
