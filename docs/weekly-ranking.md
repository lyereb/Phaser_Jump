# 本地周排行榜

## 使用与界面

主菜单点击“排行榜”打开独立窗口。只借鉴参考图的粗描边、明亮蓝色、奶油底色和金色卡通质感，不沿用其五条纵向大卡和奖励盒布局。现在使用一个冠军聚焦区、四张双列名次卡和独立的个人周最佳区；前5名均显示临时头像、姓名与米数。玩家入榜后卡片为蓝色高亮。

窗口内显示本周日期与换周倒计时，并明确标注“本地模拟榜”。右上X、底部关闭、Escape都返回原主菜单；“开始挑战”直接进入新局。窗口期间主菜单暂停，遮罩不会穿透点击，重复点击不会开多个场景。

局内已接入无框顶部追赶行：只显示周榜上一名的头像与“距离超越某某还剩多少米”，剩余数字用原黄色艺术字，按本局真实米数计算，不显示ID或目标总米数。真正超过并刷新周最佳时播放“成功超越某某某”的夸张大字回弹、双侧礼花彩纸、星爆和冲击环，立即切换下一名；周榜已第一时显示登顶鼓励。以前超过的目标不在低分重开时重复庆祝，庆祝不暂停游戏。完整口径和示例见 `docs/rank-chase.md`。

## 临时数据与真实排序

| 初始排名 | 临时用户 | 米数 |
| --- | --- | ---: |
| 1 | 小明 | 1000 |
| 2 | 小红 | 800 |
| 3 | 小刚 | 600 |
| 4 | 小李 | 400 |
| 5 | 小夏 | 200 |

五个bot是固定占位，头像为六套不同配色的本地卡通头像，并非真实用户照片。当前玩家名为“我”。这些数据不表示真实联网排名，没有服务器、好友数据、发奖或账号同步。

玩家用**本周最高真实米数**参加降序排序，只展示前5名。210米成为第5名，200米bot被挤出；410米成为第4名；1001米成为第1名。只显示五名，不把玩家额外追加成第六张卡。玩家榜外时，个人区域仍显示本周最佳及进前五的差距。

同分由bot先排，因此200米尚未入榜，201米可进入第5名。更低新局不能覆盖已有最佳。分数在每次成功落地更新时立即保存，弹簧仍按整次固定10米记录；不用等失败或结算，途中返回菜单也不丢已取得成绩。超过1000米仍正常参与排名。

## 本地保存与周切换

正常存储键为 `phaser-jump-weekly-leaderboard`，内容为 `{weekKey,best}`。本周范围按设备本地时间，从周一00:00到下周一00:00；周键为周一的本地YYYY-MM-DD，而不是UTC日期。

重开、返回菜单和刷新会保留本周最佳。周一换周时玩家最高分归零，五个临时bot继续占位，不沿用上周玩家成绩。已打开的窗口每秒重新读取状态，其他实例的更新和换周也能自动显示。没有追溯启用功能前未保存的旧成绩。

存储损坏或浏览器禁止写入不会阻断游戏，改为当前运行期内存保存；若存储完全不可用，重新加载页面后无法保留成绩。此为降级行为，不是后端存档。
