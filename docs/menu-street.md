# 主菜单无限街道：2.5D 动态背景

已在现有 Phaser 4.2.1 工程中接入程序化透视街道，不重新初始化工程、不替换引擎、不使用循环视频。正式入口与原有玩法保持不变；刷新正在运行的本地游戏即可查看。

## 原图分析与制作方案

原背景 `public/assets/UI/menu.png` 为 1152×2048 的竖屏卡通街道：中央道路指向约 59% 高度处的消失点，蓝天占据上半部，两侧商铺采用桃粉、奶黄、青绿与蓝色玻璃配色，上海城市天际线位于路尽头。Logo 在上部、餐盒与骑手在中央、按钮在下部，街道两侧是主要可见运动区域。

整图滚动会同时移动天空、远景和消失点，也会在循环处露出接缝。因此本次将天空、城市远景独立为稳定图层，用三款可重复使用的商铺立面生成两侧房屋，并以世界空间投影绘制道路、虚线、人行道、路缘接缝和绿树。仍为固定视角 2.5D，不是支持任意旋转摄像头的完整 3D 城市。

路面不是一张向下平移的图片：灰蓝底色由程序绘制，白色虚线、路缘接缝按同一世界距离投影，因此从远到近的间距、宽度和速度自然增大。

## 实现结构

`src/game/menuStreetModel.ts` 负责世界参数、深度循环、近裁剪和投影。`src/game/menuStreet.ts` 负责贴图、道路、树木、房屋对象池、绘制和销毁。`src/game/menu.ts` 在原预加载流程中加入五张资源，`src/game/scenes/MainMenu.ts` 仅替换背景创建、更新、缩放与清理调用。

投影为 `screenX = width/2 + worldX*focal/z`，`screenY = horizon + (cameraHeight-worldY)*focal/z`。房屋向摄像头靠近时 z 减小，向左右外侧放大，道路标记向屏幕下方推进。天空与远景不参与世界距离更新，UI 和角色也不加入背景对象池，不移动主摄像头。

两侧各 24 栋房屋固定复用，三款立面与不同高度交替排列，右侧错开约 42% 房屋间距。WebGL 使用 Phaser 4 `Mesh2D`，每面沿纵深分为 12 段，减少透视贴图拉伸；Canvas 模式用相同投影和纹理三角形绘制，以 30 次/秒刷新上限限制开销。Canvas 中房屋和树木在同一远到近绘制序列内，不让远树覆盖近树。

房屋不是一到摄像头前方就立刻重置：先裁掉穿过近裁剪面的部分，等整栋房屋的远端也经过摄像头之后，才在远端雾化补入。这修正了宽屏下尾部仍可见时提前消失的问题。房屋、虚线与路缘采用同一循环周期，长时间运行也不会因距离累计重置而不同步。

## 可调参数

在 `menuStreetModel.ts` 的 `STREET` 中，`speed: 0.8` 为当前慢速前进速度，单位为世界单位/秒。若希望更慢，可改为 `0.5` 或 `0.6`；希望更明显可改为 `1.0`。帧增量最多取 50 毫秒，避免窗口恢复时突然跃进。

`horizon: 0.59` 决定道路消失点高度，`focal: 0.80` 决定透视强度，`cameraHeight: 2.4` 决定视点相对路面高度。保持当前参数即可复现本次构图。房屋间距和路标周期相互关联，不建议只改一个周期参数。

## 保留行为与验证

真实浏览器验证确认，竖屏下 Logo、五个按钮、餐盒和骑手的位置与缩放值全部等于改动前基线。原点击跳跃、着地压缩、星光、开始游戏、排行榜、皮肤与设置入口保持原逻辑。弹窗通过暂停 MainMenu 同步冻结背景；关闭后继续同一进度。开始游戏时背景销毁，回到菜单只创建一套新对象池。

本次仅适配背景的竖横屏投影，不重新设计原有 UI 的横屏排版；原有宽屏菜单布局中的大 Logo 与按钮重叠未在本次改动范围内。

验证结果：12 项数学/循环检查、14 项本机 Chrome 无头浏览器真实场景检查通过，覆盖 WebGL 和 Canvas、宽屏近裁剪、暂停恢复、菜单跳跃、场景退出重建。连续调用 20,000 次 50 毫秒更新，相当于模拟 16 分 40 秒，菜单子对象数量 156、纹理数量 36 均未增长。`tsc --noEmit` 和 `npm run build` 通过。原红色加速盒 37 项回归也通过。

旧设置测试文件仍包含 `jump` 音效音量为 0.5 的断言，但当前 `audio.ts` 已无该音效键，额外运行时在这条旧断言停止；本次没有改动音频源码或为迁就旧测试修改音效。设置弹窗的背景冻结、恢复和关闭路径已由本次真实浏览器测试独立验证。

验证工具与报告保留在 `.work/menu-street/`：`test_model.cjs`、`browser_qa.cjs`、`validation/model-results.json`、`validation/browser-results.json`。真实浏览器使用任务独立 Chrome profile，不修改用户浏览器与正式游戏的金币、皮肤或声音存储。修改前文件备份在 `.work/menu-street/backups/`。
