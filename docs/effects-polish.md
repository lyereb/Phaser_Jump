# 道具与checkpoint：克制的视觉精修

本次在原有卡通风格内提升光感、运动层次与收束，不更换道具图案，不增加屏幕级闪白、爆炸或额外镜头震动。核心原则是让小特效的大小、透明度、节奏与方向更有主次，而不是把粒子数量整体翻倍。

## 画面变化

金币保留原数量和弹出动作，随后沿柔和的二次贝塞尔弧线飞向左上角计数器；加入短寿命尾部微光和少量到达闪星。飞行中与到达时读取最新HUD目标，因此窗口改变尺寸后仍向当前计数器收束。

护盾保留原蓝色轮廓与环绕光点，减少实心亮面，加入更细的边缘高光和获取时的轻涟漪，角色表情更清楚。抵挡时用短暂的低透明辉光、小碎片与细闪星取代原先较厚的亮块；碎片由14片减到10片，尺寸也变小。环绕运动以场景时间驱动，不再按每次绘制调用累加角度。

弹簧保留原冲刺提示，启动时有扁平涟漪与向上的短闪星，实际飞行时增加脚后方三股短促、渐细的金色尾光；尾光最长约155个世界像素，动作结束或失败立即隐藏。加速盒保留原红橙色分层线条和道具原色，排气亮面更轻、脉动更舒缓，拾取时增加短涟漪和少量暖色闪星，不改变盒子的运动速度。

checkpoint 保留袋子挤压、左右拆开、绳子淡出及原声音。拆开时增加两层带缺口的细涟漪与12个大小有主次的暖色闪星，彩屑由26片减为18片，尺寸更小、颜色更柔和、下落更轻。大块闪白的初始透明度由0.85降为0.13，不让亮块盖过角色与落点。

## 保持不变

未修改道具概率、金币奖励、护盾次数、弹簧计分、碰撞、原UI或0～500米背景映射。加速仍是后续5个移动盒提速30%；弹簧真实落地和自动飞行仍只奖励10米；checkpoint沿用当前工程的每50米目标和原触碰规则。`Game.ts` 相对本次备份只有两处视觉调用变化：接入弹簧尾光，以及把加速提示入口替换为包含同一提示的 `speedGranted`。

## 轻量化与生命周期

`src/game/accentEffectsModel.ts` 管理短闪星与涟漪。每个粒子池最多64个闪星、8个涟漪，单次最多20个闪星；常规拾取通常仅8～12个。每四个闪星中一个略大，其余较小，避免整组同样大小的亮点。闪星约0.48～0.86秒退场，金币尾部微光仅0.24秒，涟漪半径上限100世界像素。

`src/game/accentEffects.ts` 使用固定Graphics图层绘制，不为每帧新增场景对象。道具世界池和checkpoint世界池各有一层；金币首次使用屏幕特效时才创建屏幕图层。暂停场景不会推进这些效果，恢复后接续；场景退出会退订更新事件并销毁图层。弹簧与加速线条也是复用的Graphics，结束时立即清空。少量旧式金币、碎片与文字对象沿用原Tween管理与销毁逻辑。

运动按解析轨迹衰减并加入轻重力；带尾线的闪星沿当前瞬时速度方向转向，不在转为下坠后仍保持最初发射方向。

## 验证及预览

9项特效模型检查、13项Chrome真实场景检查通过，覆盖六类视觉调用、自然退场、暂停恢复、100次同时请求的预算、轨迹隐藏、深色太空画面、真实弹簧落地/飞行/10米计分以及退出清理；浏览器未记录运行时异常。原12项道具规则、6项弹簧模型、37项加速盒断言与15项500米背景模型通过。旧加速测试在本次工作目录补齐了工程已有倒计时和新视觉接口的替身，未改原断言或玩法源码。

类型检查通过。现有生产配置要求 `PACK_TARGET=test/prod`，本次按test做Vite打包验证，输出在 `.work/effects-polish/build/`，不覆盖用户原有 `dist/`。正式打包继续使用原 `打包.cmd` 选择环境。本次没有Git提交、上传或发布。

`outputs/effects-polish/effects-comparison.png` 为上排精修前、下排精修后的真实画面对照，从左到右是金币、护盾、checkpoint；`checkpoint-preview.gif` 为真实拆袋截图序列，用于观察展开与衰减节奏，不是游戏内使用的循环视频。对照页为了固定构图暂停了物理运动并直接调用原特效API，成绩与钱包保持不变；真实弹簧检查另行恢复正常游戏模拟。

刷新 `http://localhost:8080/` 可体验，或用原有“调试”入口逐项触发道具与checkpoint预览。本次源码备份、模型/场景报告和审查修正记录在 `.work/effects-polish/`。

## 后续微调

想再稍华丽一些，优先调整常规burst数量或少量大星芒尺寸，不建议同时提高填充透明度和整个粒子池上限。想更轻一些，可降低 `AccentEffects.paint` 中闪星的0.78透明度倍率、波纹0.48倍率，或减少各拾取入口的burst数量。加速脉动与金币弧线、弹簧尾光长度分别在 `itemEffects.ts`，checkpoint彩屑数量与大块辉光透明度在 `checkpoints.ts`。这些均为独立视觉参数，无需调整奖励或运动模型。
