# 局内周榜追赶与超越特效

## 界面与交互

金币仍在左上，菜单仍在右上。两者下方只显示临时骑手头像与**“距离超越小夏还剩 201 米”**，没有外框、底色、阴影、ID或目标总米数等细节。文字为奶白色粉棕描边，其中剩余数字直接复用 `UI/letters.png` 原黄色艺术数字贴图，不是普通字体；默认数字高48像素，整行响应式居中，超长距离适当缩放。

追赶行下方保留本局米数的原黄色大艺术字，默认高度仍为96像素；起跳提示在大米数下面，调试入口在追赶行下方右侧。超越庆祝位于大米数下方，避开顶部头像与角落菜单。追赶行与庆祝大字固定于屏幕，点击文字不会穿透起跳；礼花只是装饰，大字以外的区域仍可正常点击起跳，不暂停或改动角色物理。

真实成功超过对手时，70号“成功超越小夏”逐字跳出，整组两次放大至1.15倍并回弹，搭配漫画放射光、半透明光晕、两个冲击环与两次星爆。左右各30张、共60张金黄／粉红／天蓝彩纸分三批沿高弧线喷射、旋转并飘落。自然时长约1.88秒，淡出实际完成后立即清理，避免低帧率下计时不同步导致不可见动效继续拦截点击；停止或退出不触发下一条庆祝。最多129个临时对象，结束全部释放。复用已有jackpot庆祝音效，没有新增音频或生图。顶部目标即时切换到下一名，不需要等待特效消失。

## 目标与距离口径

目标取玩家**本周排名上一名**，不会在低分重开时重新追赶本周早已超过的对手。剩余距离按**本局当前真实米数**计算：`目标米数 - 本局米数 + 1`。这与周榜同分bot优先的规则一致，同分不是超越。

| 情况 | 顶部显示与庆祝 |
| --- | --- |
| 尚无本周成绩，开局0米 | 追赶小夏200米，还剩201米 |
| 本局199米 | 还差2米超过小夏 |
| 本局200米 | 还差1米，不播放超越 |
| 本局真实落地199→201米 | 成功超越小夏；切到400米小李，还剩200米 |
| 本周最佳210米，新局0米 | 仍追赶400米小李，本局还需401米，不重播小夏庆祝 |
| 本周最佳已经1001米，新局0米 | 显示“你已经是第一名了／继续刷新记录吧”，不回放旧庆祝 |

只有本局真实米数刷新周最佳并超过新对手时庆祝。同一目标不重复播放，其他实例更新周榜只静默更新目标。一次加分超过多名对手时，按从低到高的顺序依次播放，榜单只保留前5名也不会漏掉刚被挤出的对手。

登顶后仍可以继续跳、继续增加真实米数；1000米竖条仍只负责显示封顶，不结束游戏。普通计分、弹簧整次固定10米、金币、护盾、checkpoint和失败结算均保持原规则。

## 暂停、换周与清理

打开退出确认时，目标状态、逐字弹跳、星光和超越队列都随整个游戏场景暂停。选择继续后从原动画状态恢复，不快进、不重复播放；返回菜单、失败结算或重开会清理旧特效，新局保留周最佳。

顶部每秒静默同步周榜。周一换周时重新选目标、清理旧周庆祝，不回放上周记录。窗口尺寸变化重新布局，淡出的跳字仍跟随新屏幕中心。

## 实现与验收

`src/game/rankChaseProgress.ts` 为无Phaser依赖的目标与超越状态机；`src/game/rankChaseHud.ts` 管理无框追赶行、艺术字距离、队列与文字触摸区域；`src/game/overtakeCelebration.ts` 管理大字、双侧彩纸、星爆、冲击环和暂停／清理；`letters.ts` 的数字组件支持行内小尺寸和父容器，原主米数接口与默认高度不变；`Game.ts` 在真实米数更新时通知组件并安排顶部布局。周榜数据模型、存储键和已有临时bot不变。

最新版整项目TypeScript类型检查和生产构建通过。36项状态机检查、15项新版真实场景检查、45项既有进度／checkpoint／道具／弹簧纯逻辑回归全部通过，共96项检查。已检查实际无框头像文案、黄色艺术字距离，以及真实超越小夏并切换小李后的大字和礼花暂停画面。

验证覆盖无框头像文案、不显示ID与目标总米数、艺术字剩余距离及超长数字、同分门槛、真实落地、弹簧跨目标、连续多名超越、已有周最佳的新局、登顶后1200米续跳、暂停恢复、失败与重开清理、换周、外部更新、相机滚动和竖横屏。另验证庆祝期间装饰礼花区域仍能点击起跳。开发验收使用独立QA存储，不修改正常金币与周榜。
